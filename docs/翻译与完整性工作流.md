# 翻译与完整性工作流

本文档展开说明 [`SKILL.md`](../SKILL.md) 中的流程，供执行完整论文翻译时参考。

## 阶段一：检查并建立覆盖清单

1. 确认输入文件是论文正文、预印本、扫描件还是网页打印件；记录总页数和实际论文页范围。
2. 先扫描目录/标题结构，并逐页提取文本。对双栏、特殊字符、公式、表格和图注，将文字提取结果与页图核对。
3. 建立按原文顺序排列的覆盖清单，至少包含：题名和元数据、摘要、关键词、每级标题、所有正文段落、公式、图表、题注、脚注、致谢、附录和参考文献。
4. 对跨页段落合并为一个内容单元；对正文中的图表引用保留其上下文位置。记录每个单元所在页码和类型。
5. 标出空白页、缺页、不可读内容、截断内容和非论文界面文字。空白或不可读不等于可静默跳过。

## 阶段二：提取与翻译

1. 以源文件为准逐个处理覆盖清单项目，不以摘要、旧译文、自动生成大纲或之前的概述作为全文翻译的替代来源。
2. 每个英文段落保持原句、数字、限制条件、引用编号和语气；紧跟一个完整中文译段。一个英文段落不能被拆散到其他段落之后，也不能把多个段落揉成一个中文总结。
3. 标题、图注、表注、脚注、说明、致谢等同样翻译。术语首次出现可写“中文术语（English term, 缩写）”，之后固定使用同一译法。
4. 引文标号、章节编号、图表编号、公式编号、单位和变量名保持一致。书目字段应与源文相符，不自行添加、删改或猜测作者、卷期、页码和DOI。
5. 遇到源文件缺损时，将缺损范围记录在清单并在成品中标明页码和影响；不利用外部资料悄悄补齐。

## 阶段三：公式、图和表

### 公式

- 保留原文数学内容和编号，不凭文本识别结果重新输入，不自行推导或修正。
- 首选提取PDF中的公式对象。若无独立对象，渲染所在页并裁切公式局部；每条公式单独检查。
- 截图应完整覆盖公式本身及编号，避免切掉上下标、根号、积分区间、分数线、运算符或等号；同时尽量不带入无关正文。
- 在HTML中将公式图放在原文对应的位置，并提供可访问的替代文字和译文解释（如果原文有相应解释）。公式图不是翻译周围段落的替代品。
- 如果公式字迹无法辨识，使用局部图保留现状并说明限制，不要猜符号。

### 图

- 保留所有原图，含子图、图例、坐标、图内标注和颜色映射，不重画图表数据。
- 图像以独立资源保存。不要贴整页论文截图；如果源PDF把图拆到多块，按照源文对应关系拼合或分别呈现，并检查没有重复、漏块或错序。
- 中英文题注均保留。嵌入图像内的文字若未重新制作，则在题注附近说明图中标签保留原语言。
- 在浏览器中逐张查看：图号是否正确，边缘是否完整，文字是否清楚，透明背景是否异常，图像是否与图注一致。

### 表

- 原表图像/对象完整保留在原文位置，确保复杂布局与原始数值可核查。
- 附近另给可读的中文表格：翻译表题、表头、行名、列名、单元格、单位、脚注及显著性标记，保持行列关系和合并表头。
- 数值、符号、范围、有效数字和空白单元格按原文照录。逐行逐列比对原表图，不能只写一段表格结论来替代完整表格。
- 如果布局特别复杂，可用横向滚动或分组表头；不可读单元格要指出位置和来源页。

## 阶段四：构建HTML

1. 设置UTF-8编码、中文文档语言、可读字体、合理行宽和响应式图像尺寸。
2. 每个正文内容单元采用“原文—译文”邻接结构，使用明显但不干扰阅读的视觉样式区分两种语言。
3. 保持目录/章节层级与原文一致。可增加文档导航，但不能改变论文内容顺序。
4. 图、表和公式均按原文阅读顺序出现，使用明确的 `<figure>` / `<figcaption>` 或语义结构。
5. 图片路径使用输出文件夹下的相对地址，文件名可排序且唯一；确保所有引用文件随交付包提供。
6. 保留读者需要的引文编号和参考文献。对用户未提供的文献部分写清楚“源文件缺失”，不要编造。

## 阶段五：双重审计

### 内容审计

- 从头到尾将覆盖清单与HTML逐项核对，确认不存在未处理的段落或内容单元。
- 抽取若干原文句子检索成品，检查全文不同位置，避免整段漏译、重复或跳过。
- 核对摘要、引言、方法、实验、结论、致谢、附录、脚注和参考文献等边界部分，防止漏掉短段落。
- 按顺序核对所有图号、表号和公式号；检查正文交叉引用与实际对象对应。
- 表格逐格核对。数字不可读或源文件缺失处应有说明。

### 视觉审计

- 在目标阅读器或浏览器中打开最终文件，检查标题、双语段落、图片、公式和表格的真实呈现。
- 滚动检查全部内容：确认相对图片链接有效、图片方向/比例正确、无裁切缺边、无整页截图误用、无重叠或空白占位。
- 重点查看公式编号与公式主体是否完整、表格是否可读、长图是否能在页面内缩放。
- 任何修改后重新核对被改部分及其链接，不因局部修复而省略最终检查。

## 完成标准

只有当覆盖清单每项均已翻译或明确记录为源文件缺失，公式、图和表都按原文顺序出现，双语对应完整，且最终文件的图像链接与布局检查通过，才报告“全文翻译完成”。如果只完成了部分页或个别表未能逐格转录，应明确报告为部分完成并标出范围。
